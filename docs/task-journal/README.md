# Task Journal

Use this folder for durable notes on meaningful tasks, especially when understanding changed or when code or data changed.

## Naming

- `YYYY-MM-DD-short-task-name.md`

## Include in each entry

- domain classification
- task request
- files inspected
- confirmed facts
- inferred behavior
- unknowns or blockers
- planned or completed change
- validation steps
- risks
- rollback notes
- next steps
